TECH2 pandas Cheat Sheet

pandas, from "panel data"

  1. Labelled tables: NumPy columns + row labels (index) + column names
  2. Tools to load, clean, select, group, combine and plot data

1. Intuition

  • Series = one column of values + an index. DataFrame = several Series that share one index (a table). import pandas as pd.
  • Index = row labels. Selecting (loc), aligning, joining (join), plotting (x-axis) and resampling (dates) all use it. Default index = 0, 1, 2, …
  • Why not NumPy? NumPy needs one type and has no names. pandas allows mixed types (text, numbers, dates), keeps column names and handles missing values (NaN).
  • Vectorised: df['Fare'] * 10 applies to every row. Never loop over rows.
  • Alignment: s1 + s2 matches equal index labels, not positions. Labels with no match → NaN.
  • Methods return a new object. Assign the result: df = df.dropna() (or use inplace=True).
  • Workflow: load → inspect → select/clean → transform → group/aggregate → combine → plot.

6. Group, aggregate, transform, resample (L4)

  • Split → apply → combine: groupby splits the rows by a key, a function runs on each group, and the results are joined back together.
  • Aggregate = one value per group → one row per group; the group keys become the index.
  • Transform = one value per original row → same length as df, so it can be stored as a new column.
  • Resample = groupby on time periods (needs a date index).

7. Concat, merge, missing values (L5)

  • Concat = stack objects on top of each other (axis=0) or side by side (axis=1), aligned on the labels of the other axis.
  • Merge = match rows by a key column, like a SQL join. Join = merge on the index.
  • Rows with no match get NaN. Then drop or fill them.
